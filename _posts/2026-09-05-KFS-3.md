# Introduction :

Without virtual memory, every program in an operating system operates directly on raw physical RAM addresses. If program A writes to physical address `0x00200000`, it can inadvertently or maliciously overwrite the code of program B or even corrupt the running kernel. Furthermore, physical RAM becomes fragmented over time, making it impossible to allocate contiguous address spaces for large applications.

The solution is **Paging**, the hardware-assisted virtual memory management mechanism built into the x86 CPU. Paging separates the **virtual address space** seen by a running thread from the **physical addresses** in RAM chips.

In **KFS-3 (Kernel From Scratch 3)**, we implement the memory subsystem of our operating system:
* Parsing physical RAM maps supplied by Multiboot.
* Writing a **Physical Memory Manager (PMM)** with a bitmap allocator.
* Building a **Virtual Memory Manager (VMM)** with two-tier page directories and page tables.
* Enabling x86 hardware paging via the `CR3` and `CR0` registers.
* Implementing dynamic kernel heap allocation (`kmalloc` and `kfree`).
* Crafting a robust **Kernel Panic** subsystem to catch and report fatal memory violations.

# Architecture of x86 Two-Tier Paging :

In 32-bit protected mode with 4 KiB pages, the CPU translates a 32-bit virtual address into a physical address using a two-level hierarchy:

```
32-bit Virtual Address:
 31                  22 21                  12 11                        0
┌──────────────────────┬──────────────────────┬───────────────────────────┐
│ Page Directory Index │   Page Table Index   │       Page Offset         │
│       (10 bits)      │       (10 bits)      │        (12 bits)          │
└──────────┬───────────┴──────────┬───────────┴─────────────┬─────────────┘
           │                      │                         │
           ▼                      │                         │
    CR3 Register                  │                         │
         │                        │                         │
         ▼                        ▼                         │
┌──────────────────┐       ┌──────────────────┐             │
│  Page Directory  │       │    Page Table    │             │
│   (1024 PDEs)    │──────►│   (1024 PTEs)    │──────┐      │
└──────────────────┘       └──────────────────┘      │      │
                                                     ▼      ▼
                                           ┌──────────────────────┐
                                           │  Physical Frame (4K) │
                                           └──────────────────────┘
```

1. **CR3 Register**: Contains the physical base address of the **Page Directory** (must be 4 KiB aligned).
2. **Page Directory**: Contains 1024 **Page Directory Entries (PDEs)** (4 KiB total). Bits 31–22 of the virtual address select one PDE.
3. **Page Table**: Selected PDE points to the physical address of a Page Table. Bits 21–12 select one **Page Table Entry (PTE)**.
4. **Physical Frame**: Selected PTE points to the base of a 4 KiB physical frame. Bits 11–0 provide the byte offset within the frame.

### PDE and PTE Bit Layout (32-bit entry)

```
 31                                       12 11   9 8 7 6 5 4 3 2 1 0
┌───────────────────────────────────────────┬──────┬─┬─┬─┬─┬─┬─┬─┬─┬─┐
│    Physical Page Frame Base Address       │ Avail│G│S│0│A│D│W│U│R│P│
│                 (20 bits)                 │      │ │ │ │ │ │ │/│/│ │
│                                           │      │ │ │ │ │ │ │S│W│ │
└───────────────────────────────────────────┴──────┴─┴─┴─┴─┴─┴─┴─┴─┴─┘
```

* **P (Present, bit 0)**: Page is currently resident in physical memory. Accessing a page with `P=0` immediately triggers a **Page Fault (#PF, exception 14)**.
* **R/W (Read/Write, bit 1)**: `0` = Read-Only, `1` = Read and Write.
* **U/S (User/Supervisor, bit 2)**: `0` = Ring 0 (Kernel-only access), `1` = Ring 3 (User access allowed).
* **PWT (Write-Through, bit 3)**: Cache write-through caching policy.
* **PCD (Cache Disabled, bit 4)**: Disables CPU L1/L2 caching for this page (crucial for MMIO hardware like VGA buffer).
* **A (Accessed, bit 5)**: Set by CPU hardware when the page is read or written.
* **D (Dirty, bit 6 - PTE only)**: Set by CPU hardware when the page is written to.
* **PS (Page Size, bit 7 - PDE only)**: `0` = 4 KiB pages, `1` = 4 MiB pages (PSE).

# Walkthrough :

## :one: Physical Memory Manager (PMM)

Before mapping virtual pages, we need to track which 4 KiB physical memory frames are available in RAM. We parse the memory map supplied by GRUB via the `multiboot_info_t` struct passed into `kmain`:

```c
/* pmm.c - Physical Memory Manager using Bitmaps */
#include "multiboot.h"
#include <stdint.h>
#include <string.h>

#define PAGE_SIZE 4096
#define BLOCKS_PER_BYTE 8

static uint32_t *pmm_bitmap = (uint32_t *)0x00100000; // Located after kernel
static uint32_t total_frames = 0;
static uint32_t used_frames  = 0;

static inline void bitmap_set(uint32_t frame) {
    pmm_bitmap[frame / 32] |= (1 << (frame % 32));
}

static inline void bitmap_clear(uint32_t frame) {
    pmm_bitmap[frame / 32] &= ~(1 << (frame % 32));
}

static inline int bitmap_test(uint32_t frame) {
    return (pmm_bitmap[frame / 32] & (1 << (frame % 32))) != 0;
}

void pmm_init(multiboot_info_t *mbi, uint32_t kernel_end) {
    // Locate free memory regions from Multiboot memory map
    multiboot_memory_map_t *mmap = (multiboot_memory_map_t *)mbi->mmap_addr;
    uint32_t max_ram = 0;

    while ((uint32_t)mmap < mbi->mmap_addr + mbi->mmap_length) {
        if (mmap->type == MULTIBOOT_MEMORY_AVAILABLE) {
            uint32_t top = mmap->addr_low + mmap->len_low;
            if (top > max_ram) max_ram = top;
        }
        mmap = (multiboot_memory_map_t *)((uint32_t)mmap + mmap->size + sizeof(mmap->size));
    }

    total_frames = max_ram / PAGE_SIZE;
    uint32_t bitmap_size = total_frames / BLOCKS_PER_BYTE;

    // Place the bitmap directly past the kernel's .bss section
    pmm_bitmap = (uint32_t *)kernel_end;
    memset(pmm_bitmap, 0xFF, bitmap_size); // Mark all frames as allocated initially

    // Re-read map and mark usable RAM frames as free
    mmap = (multiboot_memory_map_t *)mbi->mmap_addr;
    while ((uint32_t)mmap < mbi->mmap_addr + mbi->mmap_length) {
        if (mmap->type == MULTIBOOT_MEMORY_AVAILABLE) {
            uint32_t start_frame = mmap->addr_low / PAGE_SIZE;
            uint32_t count = mmap->len_low / PAGE_SIZE;
            for (uint32_t i = 0; i < count; i++) {
                bitmap_clear(start_frame + i);
            }
        }
        mmap = (multiboot_memory_map_t *)((uint32_t)mmap + mmap->size + sizeof(mmap->size));
    }

    // Reserve low 1MB and kernel code/bitmap itself
    uint32_t reserved_frames = ((uint32_t)pmm_bitmap + bitmap_size) / PAGE_SIZE + 1;
    for (uint32_t i = 0; i < reserved_frames; i++) {
        bitmap_set(i);
    }
}

uint32_t pmm_alloc_frame(void) {
    for (uint32_t i = 0; i < total_frames / 32; i++) {
        if (pmm_bitmap[i] != 0xFFFFFFFF) { // Has at least one free bit
            for (int bit = 0; bit < 32; bit++) {
                if (!(pmm_bitmap[i] & (1 << bit))) {
                    uint32_t frame = i * 32 + bit;
                    bitmap_set(frame);
                    used_frames++;
                    return frame * PAGE_SIZE;
                }
            }
        }
    }
    return 0; // Out of physical memory
}

void pmm_free_frame(uint32_t frame_addr) {
    uint32_t frame = frame_addr / PAGE_SIZE;
    bitmap_clear(frame);
    used_frames--;
}
```

## :two: Virtual Memory Manager (VMM) & Two-Tier Paging

We initialize the Page Directory and identity map the first 8 MiB of memory so the kernel code and VGA buffer can continue executing uninterrupted after paging is turned on:

```c
/* vmm.h & vmm.c - Virtual Memory Management */
#define PAGE_PRESENT  0x1
#define PAGE_WRITE    0x2
#define PAGE_USER     0x4

__attribute__((aligned(4096))) static uint32_t kernel_page_directory[1024];
__attribute__((aligned(4096))) static uint32_t first_page_table[1024];
__attribute__((aligned(4096))) static uint32_t second_page_table[1024];

void vmm_init(void) {
    // Clear directory
    for (int i = 0; i < 1024; i++) {
        kernel_page_directory[i] = 0x00000002; // R/W, Not Present
    }

    // Identity map first 4MB (0x00000000 - 0x003FFFFF)
    for (uint32_t i = 0; i < 1024; i++) {
        first_page_table[i] = (i * PAGE_SIZE) | (PAGE_PRESENT | PAGE_WRITE);
    }

    // Identity map next 4MB (0x00400000 - 0x007FFFFF)
    for (uint32_t i = 0; i < 1024; i++) {
        second_page_table[i] = (0x00400000 + (i * PAGE_SIZE)) | (PAGE_PRESENT | PAGE_WRITE);
    }

    // Assign page tables to directory
    kernel_page_directory[0] = ((uint32_t)first_page_table) | (PAGE_PRESENT | PAGE_WRITE);
    kernel_page_directory[1] = ((uint32_t)second_page_table) | (PAGE_PRESENT | PAGE_WRITE);

    // Load page directory and enable paging in CR0
    vmm_enable_paging((uint32_t)kernel_page_directory);
}
```

## :three: Enabling Paging in Assembly

To enable paging, the physical base address of `kernel_page_directory` is placed into `CR3`, and bit 31 (`PG`) of `CR0` is set to 1:

```nasm
; paging_enable.s - Enable hardware paging
[BITS 32]
global vmm_enable_paging

vmm_enable_paging:
    mov eax, [esp + 4]      ; Get Page Directory address argument
    mov cr3, eax            ; Store in CR3

    mov eax, cr0
    or eax, 0x80000000      ; Set bit 31 (Paging flag - PG)
    mov cr0, eax            ; Write back to CR0 to activate MMU
    ret
```

When modifying existing mappings in a live page table, the CPU's **Translation Lookaside Buffer (TLB)** must be invalidated for that address:

```c
static inline void vmm_flush_tlb_page(uint32_t virtual_addr) {
    __asm__ volatile ("invlpg (%0)" : : "r"(virtual_addr) : "memory");
}
```

## :four: Mapping & Unmapping Pages Dynamically

```c
void vmm_map_page(uint32_t virt, uint32_t phys, uint32_t flags) {
    uint32_t pde_idx = virt >> 22;
    uint32_t pte_idx = (virt >> 12) & 0x03FF;

    uint32_t *page_table;

    // Check if page table is present
    if (!(kernel_page_directory[pde_idx] & PAGE_PRESENT)) {
        // Allocate a new page table frame from PMM
        uint32_t pt_phys = pmm_alloc_frame();
        memset((void *)pt_phys, 0, PAGE_SIZE);
        kernel_page_directory[pde_idx] = pt_phys | (flags | PAGE_PRESENT);
        page_table = (uint32_t *)pt_phys;
    } else {
        page_table = (uint32_t *)(kernel_page_directory[pde_idx] & ~0xFFF);
    }

    page_table[pte_idx] = (phys & ~0xFFF) | (flags | PAGE_PRESENT);
    vmm_flush_tlb_page(virt);
}
```

## :five: Kernel Heap Allocator (`kmalloc` & `kfree`)

We implement a boundary-tag linked-list heap allocator operating on virtual memory above the kernel:

```c
/* kheap.c - Kernel Dynamic Memory Allocator */
#include "vmm.h"
#include <stddef.h>

#define HEAP_START 0x00800000  // 8MB virtual address
#define HEAP_MAGIC 0x19283746

struct heap_block {
    uint32_t magic;
    size_t   size;
    int      is_free;
    struct heap_block *next;
};

static struct heap_block *heap_head = NULL;
static uint32_t heap_current_top = HEAP_START;

void *kmalloc(size_t size) {
    // Align allocations to 8 bytes
    size = (size + 7) & ~7;

    struct heap_block *curr = heap_head;
    while (curr) {
        if (curr->is_free && curr->size >= size) {
            curr->is_free = 0;
            return (void *)((uint32_t)curr + sizeof(struct heap_block));
        }
        curr = curr->next;
    }

    // Need more memory: map pages as needed
    size_t total_needed = size + sizeof(struct heap_block);
    while (heap_current_top + total_needed > HEAP_START + PAGE_SIZE) {
        uint32_t frame = pmm_alloc_frame();
        vmm_map_page(heap_current_top, frame, PAGE_PRESENT | PAGE_WRITE);
        heap_current_top += PAGE_SIZE;
    }

    struct heap_block *new_block = (struct heap_block *)heap_current_top;
    new_block->magic = HEAP_MAGIC;
    new_block->size = size;
    new_block->is_free = 0;
    new_block->next = heap_head;
    heap_head = new_block;

    return (void *)((uint32_t)new_block + sizeof(struct heap_block));
}

void kfree(void *ptr) {
    if (!ptr) return;
    struct heap_block *block = (struct heap_block *)((uint32_t)ptr - sizeof(struct heap_block));
    if (block->magic == HEAP_MAGIC) {
        block->is_free = 1;
        // Merge adjacent free blocks...
    }
}
```

## :six: The Kernel Panic Subsystem

When an unrecoverable hardware exception occurs (such as a Page Fault on a non-mapped address or NULL pointer dereference), the kernel must halt safely while presenting diagnostic forensics:

```c
/* panic.c - Kernel Panic and Blue Screen */
#include "vga.h"
#include "printk.h"

void kernel_panic(const char *reason, const char *file, int line) {
    // Disable interrupts to freeze system state
    __asm__ volatile ("cli");

    // Change VGA color to White on Blue (BSOD style) or White on Red
    vga_set_color(VGA_COLOR_WHITE, VGA_COLOR_BLUE);
    vga_clear();

    printk("*****************************************************************\n");
    printk("                    KERNEL PANIC : SYSTEM HALTED                 \n");
    printk("*****************************************************************\n\n");
    printk("Assertion / Panic Reason: %s\n", reason);
    printk("Location: %s:%d\n\n", file, line);

    // Read control registers
    uint32_t cr0, cr2, cr3;
    __asm__ volatile ("mov %%cr0, %0" : "=r"(cr0));
    __asm__ volatile ("mov %%cr2, %0" : "=r"(cr2)); // Faulting linear address
    __asm__ volatile ("mov %%cr3, %0" : "=r"(cr3)); // Page directory physical base

    printk("CPU Control Registers:\n");
    printk("  CR0: 0x%08x (PE=%d, PG=%d)\n", cr0, (cr0 & 1), ((cr0 >> 31) & 1));
    printk("  CR2: 0x%08x (Faulting Virtual Address)\n", cr2);
    printk("  CR3: 0x%08x (Page Directory Physical Base)\n\n", cr3);

    // Call KFS-2 Stack Backtrace
    kernel_backtrace(10);

    printk("\nSystem halted. Power cycle or reset the machine.");

    // Loop halt
    for (;;) {
        __asm__ volatile ("hlt");
    }
}
```

# Key Takeaways & What's Next :

KFS-3 transforms our toy kernel into an operating system with true virtual memory. We have:
1. Isolated virtual addresses from physical memory frames.
2. Built a complete two-tier paging system that activates hardware translation.
3. Implemented a dynamic heap allocator (`kmalloc` / `kfree`).
4. Designed a crash report diagnostic engine ready to intercept Page Faults (`CR2`).

At this stage, our kernel still operates in a strictly synchronous, polled world. Peripheral devices cannot interrupt the CPU. In **KFS-4**, we will configure the **Interrupt Descriptor Table (IDT)**, remap the **Dual 8259 PIC**, and write an interrupt-driven **PS/2 Keyboard Driver**.

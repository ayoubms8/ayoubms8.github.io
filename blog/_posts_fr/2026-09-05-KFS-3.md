# Introduction :

Sans mémoire virtuelle, chaque programme d'un système d'exploitation manipule directement des adresses physiques brutes en RAM. Si un programme A écrit à l'adresse physique `0x00200000`, il peut accidentellement ou malicieusement écraser le code d'un programme B ou corrompre le noyau en cours d'exécution. De surcroît, la RAM physique se fragmente au fil du temps, rendant impossible l'allocation d'espaces d'adresses contigus pour de volumineuses applications.

La solution réside dans la **Pagination** (*Paging*), le mécanisme matériel de gestion de mémoire virtuelle intégré au processeur x86. La pagination découple l'**espace d'adressage virtuel** perçu par un thread d'exécution des **adresses physiques** réellement implantées sur les puces de RAM.

Dans **KFS-3 (Kernel From Scratch 3)**, nous implémentons le sous-système de mémoire de notre système d'exploitation :
* Analyse de la carte de la mémoire physique transmise par Multiboot.
* Écriture d'un **Gestionnaire de Mémoire Physique (PMM)** avec allocateur à bitmap.
* Conception d'un **Gestionnaire de Mémoire Virtuelle (VMM)** avec répertoires et tables de pages à deux niveaux.
* Activation de la pagination matérielle x86 via les registres de contrôle `CR3` et `CR0`.
* Implémentation d'une allocation dynamique sur le tas noyau (*kernel heap*) avec `kmalloc` et `kfree`.
* Élaboration d'un sous-système robuste de **Panique Noyau** (*Kernel Panic*) pour intercepter et diagnostiquer les violations mémoire critiques.

# Architecture de la Pagination x86 à Deux Niveaux :

En mode protégé 32 bits avec des pages de 4 Kio, le CPU traduit une adresse virtuelle 32 bits en adresse physique grâce à une hiérarchie à deux niveaux :

```
Adresse Virtuelle 32 bits :
 31                  22 21                  12 11                        0
┌──────────────────────┬──────────────────────┬───────────────────────────┐
│ Index Répertoire Page│  Index Table de Page │      Décalage Page        │
│       (10 bits)      │       (10 bits)      │        (12 bits)          │
└──────────┬───────────┴──────────┬───────────┴─────────────┬─────────────┘
           │                      │                         │
           ▼                      │                         │
      Registre CR3                │                         │
         │                        │                         │
         ▼                        ▼                         │
┌──────────────────┐       ┌──────────────────┐             │
│ Répertoire Page  │       │  Table de Page   │             │
│   (1024 PDEs)    │──────►│   (1024 PTEs)    │──────┐      │
└──────────────────┘       └──────────────────┘      │      │
                                                     ▼      ▼
                                           ┌──────────────────────┐
                                           │  Cadre Physique (4K) │
                                           └──────────────────────┘
```

1. **Registre CR3** : Contient l'adresse physique de base du **Répertoire de Pages** (alignée sur 4 Kio).
2. **Répertoire de Pages** : Contient 1024 **Entrées de Répertoire de Pages (PDE)** (4 Kio au total). Les bits 31 à 22 de l'adresse virtuelle sélectionnent une entrée PDE.
3. **Table de Pages** : L'entrée PDE sélectionnée pointe vers l'adresse physique d'une Table de Pages. Les bits 21 à 12 sélectionnent une **Entrée de Table de Pages (PTE)**.
4. **Cadre Physique (Frame)** : La PTE sélectionnée pointe vers l'adresse de base d'un cadre physique de 4 Kio. Les bits 11 à 0 fournissent le décalage (*offset*) en octets dans ce cadre.

### Disposition Binaire d'une Entrée PDE et PTE (32 bits)

```
 31                                       12 11   9 8 7 6 5 4 3 2 1 0
┌───────────────────────────────────────────┬──────┬─┬─┬─┬─┬─┬─┬─┬─┬─┐
│     Adresse de Base du Cadre Physique     │ Dispo│G│S│0│A│D│W│U│R│P│
│                 (20 bits)                 │      │ │ │ │ │ │ │/│/│ │
│                                           │      │ │ │ │ │ │ │S│W│ │
└───────────────────────────────────────────┴──────┴─┴─┴─┴─┴─┴─┴─┴─┴─┘
```

* **P (Present, bit 0)** : La page est actuellement résidente en mémoire physique. Accéder à une page avec `P=0` déclenche immédiatement un **Défaut de Page (#PF, exception 14)**.
* **R/W (Read/Write, bit 1)** : `0` = Lecture seule, `1` = Lecture et Écriture.
* **U/S (User/Supervisor, bit 2)** : `0` = Ring 0 (Accès réservé au noyau), `1` = Ring 3 (Accès utilisateur autorisé).
* **PWT (Write-Through, bit 3)** : Politique de cache en écriture directe.
* **PCD (Cache Disabled, bit 4)** : Désactive le cache CPU L1/L2 pour cette page (indispensable pour les zones d'E/S mappées en mémoire comme le tampon VGA).
* **A (Accessed, bit 5)** : Positionné par le matériel CPU lors d'une lecture ou d'une écriture sur la page.
* **D (Dirty, bit 6 - PTE uniquement)** : Positionné par le CPU lorsqu'une écriture intervient dans la page.
* **PS (Page Size, bit 7 - PDE uniquement)** : `0` = pages de 4 Kio, `1` = pages géantes de 4 Mio (PSE).

# Déroulement du Projet :

## :one: Gestionnaire de Mémoire Physique (PMM)

Avant de cartographier des pages virtuelles, nous devons suivre les cadres de mémoire physique de 4 Kio disponibles dans la RAM. Nous analysons la carte mémoire fournie par GRUB via la structure `multiboot_info_t` transmise à `kmain` :

```c
/* pmm.c - Gestionnaire de Mémoire Physique avec Bitmap */
#include "multiboot.h"
#include <stdint.h>
#include <string.h>

#define PAGE_SIZE 4096
#define BLOCKS_PER_BYTE 8

static uint32_t *pmm_bitmap = (uint32_t *)0x00100000; // Situé après le noyau
static uint32_t total_frames = 0;
static uint32_t used_frames  = 0;

static inline void bitmap_set(uint32_t frame) {
    pmm_bitmap[frame / 32] |= (1 << (frame % 32));
}

static inline void bitmap_clear(uint32_t frame) {
    pmm_bitmap[frame / 32] &= ~(1 << (frame % 32));
}

static inline int bitmap_test(uint32_t frame) {
    return (pmm_bitmap[frame / 32] & (1 << (frame % 32))) != 0;
}

void pmm_init(multiboot_info_t *mbi, uint32_t kernel_end) {
    // Localisation des zones de mémoire libre depuis la carte Multiboot
    multiboot_memory_map_t *mmap = (multiboot_memory_map_t *)mbi->mmap_addr;
    uint32_t max_ram = 0;

    while ((uint32_t)mmap < mbi->mmap_addr + mbi->mmap_length) {
        if (mmap->type == MULTIBOOT_MEMORY_AVAILABLE) {
            uint32_t top = mmap->addr_low + mmap->len_low;
            if (top > max_ram) max_ram = top;
        }
        mmap = (multiboot_memory_map_t *)((uint32_t)mmap + mmap->size + sizeof(mmap->size));
    }

    total_frames = max_ram / PAGE_SIZE;
    uint32_t bitmap_size = total_frames / BLOCKS_PER_BYTE;

    // Positionnement du bitmap immédiatement après la section .bss du noyau
    pmm_bitmap = (uint32_t *)kernel_end;
    memset(pmm_bitmap, 0xFF, bitmap_size); // Marque tous les cadres comme alloués initialement

    // Relecture de la carte et libération des zones de RAM exploitables
    mmap = (multiboot_memory_map_t *)mbi->mmap_addr;
    while ((uint32_t)mmap < mbi->mmap_addr + mbi->mmap_length) {
        if (mmap->type == MULTIBOOT_MEMORY_AVAILABLE) {
            uint32_t start_frame = mmap->addr_low / PAGE_SIZE;
            uint32_t count = mmap->len_low / PAGE_SIZE;
            for (uint32_t i = 0; i < count; i++) {
                bitmap_clear(start_frame + i);
            }
        }
        mmap = (multiboot_memory_map_t *)((uint32_t)mmap + mmap->size + sizeof(mmap->size));
    }

    // Réservation du premier mégaoctet (1 Mo) ainsi que du code noyau et du bitmap
    uint32_t reserved_frames = ((uint32_t)pmm_bitmap + bitmap_size) / PAGE_SIZE + 1;
    for (uint32_t i = 0; i < reserved_frames; i++) {
        bitmap_set(i);
    }
}

uint32_t pmm_alloc_frame(void) {
    for (uint32_t i = 0; i < total_frames / 32; i++) {
        if (pmm_bitmap[i] != 0xFFFFFFFF) { // Possède au moins un bit libre
            for (int bit = 0; bit < 32; bit++) {
                if (!(pmm_bitmap[i] & (1 << bit))) {
                    uint32_t frame = i * 32 + bit;
                    bitmap_set(frame);
                    used_frames++;
                    return frame * PAGE_SIZE;
                }
            }
        }
    }
    return 0; // Mémoire physique épuisée
}

void pmm_free_frame(uint32_t frame_addr) {
    uint32_t frame = frame_addr / PAGE_SIZE;
    bitmap_clear(frame);
    used_frames--;
}
```

## :two: Gestionnaire de Mémoire Virtuelle (VMM) & Pagination à Deux Niveaux

Nous initialisons le Répertoire de Pages et réalisons un mappage direct (*identity mapping*) des 8 premiers mégaoctets afin que le code noyau et le tampon VGA continuent de s'exécuter sans interruption après l'activation de la pagination :

```c
/* vmm.h & vmm.c - Gestionnaire de Mémoire Virtuelle */
#define PAGE_PRESENT  0x1
#define PAGE_WRITE    0x2
#define PAGE_USER     0x4

__attribute__((aligned(4096))) static uint32_t kernel_page_directory[1024];
__attribute__((aligned(4096))) static uint32_t first_page_table[1024];
__attribute__((aligned(4096))) static uint32_t second_page_table[1024];

void vmm_init(void) {
    // Initialisation du répertoire
    for (int i = 0; i < 1024; i++) {
        kernel_page_directory[i] = 0x00000002; // R/W, Non Présent
    }

    // Identity mapping des 4 premiers Mo (0x00000000 - 0x003FFFFF)
    for (uint32_t i = 0; i < 1024; i++) {
        first_page_table[i] = (i * PAGE_SIZE) | (PAGE_PRESENT | PAGE_WRITE);
    }

    // Identity mapping des 4 Mo suivants (0x00400000 - 0x007FFFFF)
    for (uint32_t i = 0; i < 1024; i++) {
        second_page_table[i] = (0x00400000 + (i * PAGE_SIZE)) | (PAGE_PRESENT | PAGE_WRITE);
    }

    // Assignation des tables au répertoire
    kernel_page_directory[0] = ((uint32_t)first_page_table) | (PAGE_PRESENT | PAGE_WRITE);
    kernel_page_directory[1] = ((uint32_t)second_page_table) | (PAGE_PRESENT | PAGE_WRITE);

    // Chargement du répertoire et activation de la pagination dans CR0
    vmm_enable_paging((uint32_t)kernel_page_directory);
}
```

## :three: Activation de la Pagination en Assembleur

Pour activer la pagination, l'adresse physique de base de `kernel_page_directory` est chargée dans `CR3`, et le bit 31 (`PG`) du registre `CR0` est positionné à 1 :

```nasm
; paging_enable.s - Activation matérielle de la pagination
[BITS 32]
global vmm_enable_paging

vmm_enable_paging:
    mov eax, [esp + 4]      ; Récupère l'adresse du répertoire passée en paramètre
    mov cr3, eax            ; Enregistre dans CR3

    mov eax, cr0
    or eax, 0x80000000      ; Active le bit 31 (Flag de pagination - PG)
    mov cr0, eax            ; Réécrit dans CR0 pour activer la MMU
    ret
```

Lors de la modification de correspondances au sein d'une table de pages active, le cache de traduction de la CPU (**Translation Lookaside Buffer - TLB**) doit être invalidé pour cette adresse :

```c
static inline void vmm_flush_tlb_page(uint32_t virtual_addr) {
    __asm__ volatile ("invlpg (%0)" : : "r"(virtual_addr) : "memory");
}
```

## :four: Mappage & Démappage Dynamique de Pages

```c
void vmm_map_page(uint32_t virt, uint32_t phys, uint32_t flags) {
    uint32_t pde_idx = virt >> 22;
    uint32_t pte_idx = (virt >> 12) & 0x03FF;

    uint32_t *page_table;

    // Vérifie si la table de pages est présente
    if (!(kernel_page_directory[pde_idx] & PAGE_PRESENT)) {
        // Alloue un nouveau cadre pour la table de pages depuis le PMM
        uint32_t pt_phys = pmm_alloc_frame();
        memset((void *)pt_phys, 0, PAGE_SIZE);
        kernel_page_directory[pde_idx] = pt_phys | (flags | PAGE_PRESENT);
        page_table = (uint32_t *)pt_phys;
    } else {
        page_table = (uint32_t *)(kernel_page_directory[pde_idx] & ~0xFFF);
    }

    page_table[pte_idx] = (phys & ~0xFFF) | (flags | PAGE_PRESENT);
    vmm_flush_tlb_page(virt);
}
```

## :five: Allocateur de Tas Noyau (`kmalloc` & `kfree`)

Nous implémentons un allocateur de tas dynamique fondé sur une liste chaînée avec balises de limites (*boundary-tag*), opérant dans la mémoire virtuelle au-dessus du noyau :

```c
/* kheap.c - Allocateur de Mémoire Dynamique Noyau */
#include "vmm.h"
#include <stddef.h>

#define HEAP_START 0x00800000  // Adresse virtuelle 8 Mo
#define HEAP_MAGIC 0x19283746

struct heap_block {
    uint32_t magic;
    size_t   size;
    int      is_free;
    struct heap_block *next;
};

static struct heap_block *heap_head = NULL;
static uint32_t heap_current_top = HEAP_START;

void *kmalloc(size_t size) {
    // Alignement des allocations sur 8 octets
    size = (size + 7) & ~7;

    struct heap_block *curr = heap_head;
    while (curr) {
        if (curr->is_free && curr->size >= size) {
            curr->is_free = 0;
            return (void *)((uint32_t)curr + sizeof(struct heap_block));
        }
        curr = curr->next;
    }

    // Mémoire insuffisante : mappage de nouvelles pages virtuelles
    size_t total_needed = size + sizeof(struct heap_block);
    while (heap_current_top + total_needed > HEAP_START + PAGE_SIZE) {
        uint32_t frame = pmm_alloc_frame();
        vmm_map_page(heap_current_top, frame, PAGE_PRESENT | PAGE_WRITE);
        heap_current_top += PAGE_SIZE;
    }

    struct heap_block *new_block = (struct heap_block *)heap_current_top;
    new_block->magic = HEAP_MAGIC;
    new_block->size = size;
    new_block->is_free = 0;
    new_block->next = heap_head;
    heap_head = new_block;

    return (void *)((uint32_t)new_block + sizeof(struct heap_block));
}

void kfree(void *ptr) {
    if (!ptr) return;
    struct heap_block *block = (struct heap_block *)((uint32_t)ptr - sizeof(struct heap_block));
    if (block->magic == HEAP_MAGIC) {
        block->is_free = 1;
        // Fusion des blocs contigus libres...
    }
}
```

## :six: Le Sous-Système de Panique Noyau (Kernel Panic)

Lorsqu'une exception matérielle irrécupérable survient (telle qu'un Défaut de Page sur une adresse non cartographiée ou le déréférencement d'un pointeur NULL), le noyau doit suspendre l'exécution en toute sécurité tout en fournissant des diagnostics complets :

```c
/* panic.c - Panique Noyau et Écran Bleu */
#include "vga.h"
#include "printk.h"

void kernel_panic(const char *reason, const char *file, int line) {
    // Désactivation des interruptions pour figer l'état du système
    __asm__ volatile ("cli");

    // Passage des couleurs VGA en Blanc sur Bleu (style BSOD) ou Blanc sur Rouge
    vga_set_color(VGA_COLOR_WHITE, VGA_COLOR_BLUE);
    vga_clear();

    printk("*****************************************************************\n");
    printk("                    KERNEL PANIC : SYSTEM HALTED                 \n");
    printk("*****************************************************************\n\n");
    printk("Raison de l'échec / Assertion : %s\n", reason);
    printk("Emplacement : %s:%d\n\n", file, line);

    // Lecture des registres de contrôle
    uint32_t cr0, cr2, cr3;
    __asm__ volatile ("mov %%cr0, %0" : "=r"(cr0));
    __asm__ volatile ("mov %%cr2, %0" : "=r"(cr2)); // Adresse virtuelle ayant fauté
    __asm__ volatile ("mov %%cr3, %0" : "=r"(cr3)); // Base physique du répertoire

    printk("Registres de Contrôle CPU :\n");
    printk("  CR0: 0x%08x (PE=%d, PG=%d)\n", cr0, (cr0 & 1), ((cr0 >> 31) & 1));
    printk("  CR2: 0x%08x (Adresse Virtuelle en Faute)\n", cr2);
    printk("  CR3: 0x%08x (Base Physique du Répertoire de Pages)\n\n", cr3);

    // Appel du Backtrace de la pile (développé dans KFS-2)
    kernel_backtrace(10);

    printk("\nSystème arrêté. Veuillez redémarrer ou éteindre la machine.");

    // Boucle d'arrêt infinie
    for (;;) {
        __asm__ volatile ("hlt");
    }
}
```

# Points Clés & Perspectives :

KFS-3 transforme notre noyau démonstratif en un système d'exploitation doté d'une véritable gestion de mémoire virtuelle :
1. **Isolation stricte** entre adresses virtuelles et cadres de mémoire physique.
2. **Système de pagination complet** à deux niveaux activant la translation matérielle de la MMU.
3. **Allocateur de tas dynamique** (`kmalloc` / `kfree`) facilitant l'instanciation d'objets en mémoire.
4. **Moteur d'analyse de crash** capable d'intercepter les défauts de page (`CR2`).

À ce stade, notre noyau évolue encore dans un modèle synchrone par scrutation. Dans **KFS-4**, nous configurerons la **Table des Descripteurs d'Interruptions (IDT)**, remapperons le **Double PIC 8259** et concevrons un **pilote de clavier PS/2** piloté par interruptions matérielles.
